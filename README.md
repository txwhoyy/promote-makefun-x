Entry for make.fun's "Promote the make-your-own-bounty post on X" bounty. The post itself is on X: a quote of @makefunai's announcement that anyone can now create their own bounty on make.fun, with an original photo and the entrant's play code. This repository carries the post's address in POST.json; the program validates that address and hands it to the grader unchanged.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
